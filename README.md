🚀 DevOps Engineer Portfolio Website (Dockerized | Cloud Ready)

A professional corporate-style portfolio website designed to showcase a comprehensive DevOps skill set, featuring curated projects and technical expertise.
## 📌 Highlights

- Production-style Dockerized portfolio
- Demonstrates DevOps engineering workflow
- Clean, recruiter-friendly design
- Built with scalability in mind
## 🚀 Project Overview
This project serves as a centralized DevOps portfolio showcasing real-world engineering practices including CI/CD, containerization, and infrastructure design.

## ✨ Key Features

- 🎯 Professional corporate-style UI using HTML, CSS, JavaScript
- 🐳 Fully containerized using Docker + Nginx
- ⚡ High-performance static site served via optimized Nginx config
- ☁️ Designed to showcase real DevOps engineering capabilities
- 📦 Highlights real projects:
  - CI/CD pipelines
  - AWS Infrastructure (Terraform)
  - Kubernetes deployments
  - Cloud-native tooling

## 🛠 Tech Stack

- Frontend: HTML5, CSS3, JavaScript
- Web Server: Nginx
- Containerization: Docker
- Cloud Concepts: CI/CD, Kubernetes, Terraform (Showcased)

## 📂 Project Structure
- `assets/`: Contains CSS, JS, and images.
- `decisions/`: Documentation of architectural and tech stack decisions.
- `Dockerfile`: Configuration for the Nginx container.
- `nginx.conf`: Custom Nginx configuration for optimized delivery.
                                                                                                                                                                                                              
## 🗺 Roadmap

- ✅ Phase 1: Static Portfolio (Completed)
- 🚧 Phase 2: Backend Integration (Node.js / Python API)
- 🚀 Phase 3: Full CI/CD + Admin Dashboard
- ☁️ Phase 4: Cloud Deployment with automated pipelines
